# Insert a fun R script section header `<(+_+)>`

Insert a section header at the cursor in RStudio or Positron (similar to
`Cmd/Ctrl + Shift + R`).

## Usage

``` r
ger_sect(name)
```

## Arguments

- name:

  section name

## Value

the section header text (invisibly)

## Examples

``` r
# with RStudio or Positron running:
# ger_sect("import")
```
