# gerp: Good Enough R Practices

This package helps users adopt a set of good enough computing practices
when working with data. The methods are largely based on the paper,
'Good enough practices in scientific computing' by Wilson et al (2017)
[doi:10.1371/journal.pcbi.1005510](https://doi.org/10.1371/journal.pcbi.1005510)
.
